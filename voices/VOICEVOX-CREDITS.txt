VOICEVOX 语音署名 / Credits
================================

本目录中的角色战吼使用 VOICEVOX 合成，并按角色分配了不同音声ライブラリ。
这些不是原版动画声优，也不包含动画原声。

音声合成：
  VOICEVOX
  https://voicevox.hiroshiba.jp/
  VOICEVOX 利用規約: https://voicevox.hiroshiba.jp/term/

使用した音声ライブラリ / Voices:
  青山龍星（ノーマル）      承太郎、流星刺指、白金之星时停
  玄野武宏（ノーマル）      DIO、时停、压路机、东方定助
  白上虎太郎（ふつう）      乔鲁诺、黄金体验、镇魂曲
  剣崎雌雄（ノーマル）      花京院、绿宝石

各音声ライブラリの利用規約に従って使用しています。
VOICEVOX のクレジット表記が必要です。

合成API:
  WEB版VOICEVOX API (tts.quest)
  https://voicevox.su-shiki.com/su-shikiapis/ttsquest/
  ※非公式API。音声はローカルに保存して再生しています。

注意：
- 本游戏不包含原版动画音频或声优表演。
- 这些语音只模拟动漫风格，不是原作者/声优的声音。

追加：透龙 / 奇迹与你
================================
  tooru_*.mp3 は VOICEVOX の青山龍星（ノーマル）で合成。
  WEB版VOICEVOX API (tts.quest) を使用。
  日本語の台詞を事前生成してローカル再生しています。
  tooru_*.wav は日本語音声が読み込めない場合の予備（Windows Speech 中国語）。

追加：东方定助 / 软又湿
================================
  josuke_*.mp3 は VOICEVOX の玄野武宏（ノーマル）で合成。
  日本語の台詞を事前生成してローカル再生しています。
  josuke_bubble_short / bubble / evolve / steal / super / finisher。

  音高調整:
    参考動画を 1 秒ごとに基本周波数分析し、画面字幕が
    「我是 [Wonder of U]」になる 17–20.5 秒の自己紹介区間を
    キャラクター音声として採用（中央値 86.5 Hz、10–90 パーセンタイル
    62–111 Hz）。11–12 秒の「De Do Do Do…」は歌詞/BGM と判断して
    除外しました。
    合成音声は asetrate=0.88 + atempo で約 86 Hz まで下げ、
    フォルマントの痩せを補うため 900 Hz 付近を +2.5 dB、
    110 Hz 付近を -2 dB、3 kHz 付近を -1.5 dB 調整しています。
    ※参考動画は実質モノラルで、声と BGM を完全分離することは
      できません。そのため「音楽の低音」ではなく、字幕と一致する
      自己紹介区間のピッチ変化を基準にしています。
